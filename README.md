# MARqentic marketing skills

26 research-focused marketing skills for AI assistants, adapted from [Manifold marketing-skills](https://github.com/manifoldmcp/marketing-skills) under the MIT license. Includes all supporting references.

## Install

After this release is published:

```sh
npx skills add Marqentic/marketing-skills
```

Select the skills and agents you use. Install one area with `--skill seo`, or add `-g` for a user-wide installation. The installer requires its supported Node.js version. See [the official skills CLI](https://github.com/vercel-labs/skills).

Start with `manifold-get-started` to write your product context and choose a workflow. This upstream identifier is intentionally retained so existing instructions remain compatible.

## Connect live research

This is a skills-only package. It does not install a connector, include credentials, or claim a directory listing. Authorize the deployed MARqentic server separately; see [connection and availability](CONNECTING.md). The knowledge and manual methods can be used without a server.

Current live coverage includes SEO, AI answers, public social research, Google Maps and supported commerce research. Google is the implemented ad-library platform. Search Console, Analytics, verified lead enrichment and X tools are not implemented; named upstream workflows use manual alternatives when these tools are absent. Prices in skill prose are reference figures; the connected server's schema and free dry-run quote are authoritative.
